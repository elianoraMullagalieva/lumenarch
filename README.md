# LumenArch

Промо-сайт архитектурного бюро: сторителлинг-скролл с видео-скрабом,
кейсы проектов, услуги и команда.

## Структура

| Экран | Что в нём |
|---|---|
| 1–2 | Hero с видео-скрабом по скроллу: `Lumen Arch` → «Берём на себя все этапы» |
| 3 | Белый манифест, из которого раскрывается кадр здания |
| 4 | Кейсы: Атриум · Импульс · Гармония — по 2 фото, слайдшоу 3 сек, табы |
| 5 | Услуги — hover image reveal, картинка следует за курсором |
| 6 | Команда — карточка с портретом, должностью и цитатой |
| 7 | Контакты и футер |

## Технологии

Один HTML-файл без сборки и зависимостей: ванильный CSS и JS.
Анимации — на `requestAnimationFrame` со сглаживанием и авто-остановкой
цикла на статике.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>.
